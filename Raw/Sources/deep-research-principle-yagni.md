## Normalized Content

YAGNI — “You Aren't Gonna Need It” — is an Extreme Programming principle against implementing functionality merely because it might become useful later. Its most precise formulation in the primary material comes from XP co-creator Ron Jeffries: “YAGNI permits us to think as much as we want about the future, but asks us to implement code only for what we need today.” YAGNI is therefore not a ban on planning, architecture, documentation, abstraction, or quality; it is a rule about when to commit implementation effort. Canonical anchors include Jeffries' original article and later retrospectives, the c2.com wiki pages (YouAreGonnaNeedIt, ExtremeNeed), Beck/Jeffries planning literature, and the Wikipedia overview; the historical record warrants caution about precise coinage claims.
