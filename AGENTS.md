# Agent Operating Rules

1. Treat `Raw/Sources/` as evidence, never compiled knowledge; never silently accept changed evidence.
2. Write reusable, focused knowledge under `Wiki/`; preserve investigation history under `Research/`, contextual history under `Memory/`, and meaningful choices under `Decisions/`.
3. Search `Wiki/catalog.jsonl`, relevant Research, and active Decisions before broad Raw reads or duplicate work. Use Memory only when it materially changes the task.
4. Build a deterministic Context Pack for complex multi-note questions.
5. Compiled notes require Raw provenance unless they are navigation/index notes. Material claims use the Evidence Ledger.
6. Never invent citations or unsupported claims. Preserve uncertainty, competing views, contradictions, and unresolved questions.
7. Prefer focused linked notes over monoliths. Supersede decisions instead of deleting history.
8. Do not turn temporary task context or one-off observations into durable Memory; validate factual Memory before Wiki promotion.
9. Catalogs, graphs, Context Packs, embeddings, databases, and site output are rebuildable and never canonical.
10. Run tests and the maintenance gate before meaningful commits. Do not enable MCP/API mutation without the documented security contract; external stores never replace canonical Markdown.
