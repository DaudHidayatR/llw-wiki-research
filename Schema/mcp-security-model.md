# MCP/API Security Model
MCP/API is optional and absent from core. If enabled, bind localhost by default; remote access requires authentication and trusted TLS/origin policy. Never wildcard CORS with authenticated mutation. Enforce narrow scopes: knowledge/read, research/read/propose, memory/read/propose, decision/read/propose, wiki/propose/review, admin/maintenance. Memory is separately sensitive; Raw and generated Context are restricted. Prefer proposal/review over direct mutation; never expose unrestricted filesystem mutation. Define rate, body, concurrency limits, redacted errors, and audits containing timestamp, principal, operation, canonical target, result, and approval reference without secrets.
