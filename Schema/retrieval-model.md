# Deterministic Retrieval Model
NFKC-normalize, casefold, tokenize Unicode alphanumerics, remove versioned stopwords, do not stem, and deduplicate query tokens. Score exact title +100, exact alias +90; distinct token hits: title +20 (cap 60), alias +15 (45), topic +10 (30), body +5 (25). Keep top eight positive seeds. One-hop additions: explicit relation +25, wikilink +20, shared source +10, active related Research/Decision +15, permitted Memory +10. Count each signal once. Sort score descending, profile type priority, updated descending, canonical path ascending; default priority synthesis, comparison, concept, topic, entity, project; select `max_items` (20). Same state/query/profile/tool yields same ranked paths. Targets: Recall@10 >= .85, MRR@10 >= .65, zero-hit <= 10%; add external retrieval only after measured failures.
