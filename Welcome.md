# Knowledge OS

This repository is a durable, human-readable Knowledge OS. Markdown with constrained YAML frontmatter and wikilinks is canonical; catalogs, graphs, context packs, and web output are disposable derived layers.

- **Raw** preserves source evidence.
- **Wiki** holds current reusable understanding.
- **Research** preserves investigation paths, uncertainty, and findings.
- **Memory** stores relevant contextual history, not universal truth.
- **Decisions** preserve choices, rationale, alternatives, consequences, and supersession.
- **Context** defines and generates task-specific knowledge bundles.

Humans should start at [Wiki/index.md](Wiki/index.md). Agents should read [AGENTS.md](AGENTS.md), then search `Wiki/catalog.jsonl` before broad Raw reads.
